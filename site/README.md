# 学习台 · 本地静态站 v1

双击 `index.html` 就能用，不需要服务器、不需要账号。

## 打开方式

- **直接双击** `index.html`（Chrome / Edge / Safari 均可）。
- 想更稳一点，起一个本地静态服务：

  ```bash
  cd learning-workbench/site && python3 -m http.server 8000
  # 打开 http://localhost:8000
  ```

数据全部在内联文件里（`data/plan.js`），所以 `file://` 下也能正常显示计划。

## 每日小测（2026-11-10 新增）

每天从题池里**抽 2 题**，共 **295 题**，每天 3–4 题，全部带标准答案和解析。

三种题型的分工：

| 题型 | 数量占比 | 考什么 | 判分 |
|---|---|---|---|
| 单选 | 约 6 成 | 概念边界、机制选择 | 自动判，选错标红并给出正确项 |
| 判断 | 约 3 成 | 常见误解（“越严格越好”“记得越多越好”） | 自动判 |
| 简答 | 约 1 成 | 归因与表达（里程碑、复盘日） | 给参考答案，自己评「答对/部分/没答上」 |

设计上有三条刻意的取舍：

1. **不考背诵，考判断**：题目几乎都问“会发生什么/该选哪个”，而不是“定义是什么”。比如「扫描版 PDF 用 Tika 抽取会得到什么」「重排之后 top1 一定更相关吗」。
2. **答错不阻塞打卡**：小测是反馈，不是门槛。做完当天仍可标记完成，避免因为一两道题卡住整条计划。
3. **错题要能回看**：答题结果存在 `days[id].quiz`，错题会显示「你选了 B」+ 正确答案 + 解析；进度页有总正确率。

**抽题机制**：按「天 id + 一个可变的 seed」做确定性洗牌，所以刷新页面抽到的还是同一组，点「换一组题」才会换。答案按原始题号存储，换组不会把答过的题当成没答。

题目按周维护在 `quizzes/*.yaml`（同一天可以出现在多个文件里，题目累加），`build.py` 会校验：每天至少 2 题、题型合法、选择题答案下标在范围内、简答题必须有参考答案，缺哪一天直接报错。

### 错题重做

错题本里每题都有「重做这题」：原地展开选项，重新作答。答对立刻移出错题本并回到当天记录，
答错则保留并提示「看一遍解析再试」。简答题可以看参考答案后自评。

### 随机刷题

进度页「随机刷题」按阶段（A 打底 / B RAG / C Agent / D 可观测与安全 / E MCP 与作品 / F 缓冲与求职）
从题库抽 5 题，答完当场判分。练习记录单独存在 `state.practice`，**不污染**当天小测成绩。

### PWA：装到手机主屏

```bash
cd learning-workbench/site && python3 -m http.server 8000
# 手机与电脑同一 WiFi，用手机打开 http://<电脑IP>:8000
# Chrome / Safari 菜单里选「添加到主屏幕」
```

- `manifest.webmanifest`：独立窗口、深色主题、192/512 图标
- `sw.js`：缓存应用外壳，**断网也能打开和答题**
- 注意：`file://` 双击打开时浏览器不允许注册 Service Worker，会静默跳过；要用 PWA 必须走 http

### 错题本

进度页的「错题本」汇总所有答错、以及自评「部分对」的题：题干、你选的答案、正确答案、解析，
点「回看这一天」跳回那天详情（详情里也会列出当天全部小测结果）。答错不影响打卡。

## 任务卡：每个任务点「怎么学」

「今日」页每个任务右侧有「怎么学」，点开是六段式任务卡：

| 段落 | 回答什么问题 |
|---|---|
| 为什么做 | 这一步在项目里的位置，值不值得花时间 |
| 学习材料 | 直接点开对应文档/视频，并标注「看哪一段」 |
| 动手步骤 | 3–6 步，可照抄，含命令和文件名 |
| 练什么 | 一个可交付的小练习 |
| 怎么算过 | 2–3 条可勾选的验收标准 |
| 常见坑 | 提前告诉你会卡在哪 |

「今天看这些」独立卡片已取消——材料只在任务卡里出现，避免「关掉卡片再去翻资料」。
需要看当天全部材料时，点任务区右上角的「本关全部材料」。

**当前覆盖**：164 / 295 个任务（91 天）
- 第 1–6 周：116 个**完整卡**（为什么/材料/步骤/练什么/怎么算过/坑）
- 第 7–14 周：48 个**轻量卡**（只有材料和 focus，步骤由当天产出物约束）

**长课自动提示分段**：超过 3 小时的课显示「全 42.8h，建议分段看」，避免被总时长劝退。没写的任务回退显示当天目标、产出物和全部资源。

**长课程要标 focus**：像尚硅谷 SpringBoot3 标的是全集 42.8 小时，当天只有 2 小时预算，
所以任务卡里必须写清「只看前 3 集，约 40 分钟」，否则材料等于没给。

添加方式：编辑 `briefs/bNN.yaml`，`build.py` 会校验任务下标、必填字段、步骤数和验收标准。

## 学习计时（有效时长）

「今日」页右栏有计时卡，**必须手动点「开始学习」**才开始记录。

| 触发 | 行为 | 原因 |
|---|---|---|
| 切到别的标签页 / 最小化 | 自动暂停，回来需手动「继续」 | 避免后台挂机虚增时长 |
| 窗口失去焦点（切到别的应用） | 自动暂停 | 同上 |
| 5 分钟无键鼠操作 | 自动暂停 | 防「开着页面去吃饭」 |
| 关闭页面 | 已计时间落盘，不补算关闭期间 | 只记录真实在场 |
| 点「完成今天」 | 结算当天总时长并冻结 | 完成后时间不再累加 |

实现要点：

- 用 `performance.now()` 计时，不受系统改时间影响
- 每 5 秒把累计毫秒落盘（`days[id].time.ms`），刷新不丢
- 刷新后不会「接着跑」，必须重新点开始——不做跨会话补算
- 进度页汇总：今天 / 本周 / 累计 / 平均每天，并和当天计划时长对比

## 解锁与顺延（2026-11-10 新增）

计划不再按日历推进，改成**按完成度推进**：

- **顺序解锁**：完成第 N 天，才解锁第 N+1 天。没解锁的天在「计划」里显示「锁定」、点了只会提示先完成第几天。
- **自动顺延**：今天没做完，不用点任何东西——明天打开，这一关还在，日期自动变成明天，后面的课程整体往后推，**不会跳天**。
- 「今天没做完，顺延」只是记一次顺延次数，方便复盘时看自己卡在哪。
- 「撤销上一次完成」把上一个完成的天退回，它重新成为今天。
- 「今日」永远显示你当前这一关的日期和内容。

**已通过的课随时回看**：进度页新增「已通过的课」列表，点「回看并记笔记」打开当天详情，
里面有一栏**复习笔记**（和当天写的笔记分开存，随时补，输入即保存）。计划页点已完成的那天也一样。

## 数据存在哪

- 打卡、笔记、疑点、复盘写在浏览器 `localStorage`，key 是 `xuetai.v1`。
- **换电脑 / 换浏览器 / 清缓存前，先到「进度 → 备份与恢复」导出 JSON。**
- 导入会覆盖当前记录（会二次确认）。

## 改计划

计划内容不在这里改。到上一层 `learning-workbench/`：

## 设计与实现

页面按 taste-skill 的流程做，用的都是它的机制，不是自己另起一套：

- **palette**：deal 结果为 `forest-pale-lime`（暗绿底 #0f1f10 + 青柠强调 #c6f19d），取第一组
- **type**：`familjen`（Familjen Grotesk + IBM Plex Mono），数字与 ID 走等宽
- **radius**：`sharp`（4/6/8），按钮 `solid`
- **基础层**：`assets/system.css` + `assets/motion/motion.css`，只加应用组件
- **刻意偏离**：关掉了 system.css 的「一屏一节」强制高度和营销页的 hero 结构——这是应用界面，不是落地页
